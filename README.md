# Автопостинг в канал MAX

Бот публикует посты из `queue/` в канал по расписанию (московское время).

- Пост = файл `queue/ГГГГ-ММ-ДД_ЧЧММ.md`, например `2026-11-03_1200.md` → 3 ноября в 12:00.
- Первая строка `button: Текст` добавляет под постом кнопку-ссылку `BUTTON_URL`.
- Опубликованные отмечаются в `published.txt` на сервере — повторно не уходят.
- Пост, опоздавший больше чем на 6 часов, не публикуется (пишется в лог).
- Секреты только в `config.env` на сервере, в git он не попадает.

Сервер раз в 5 минут делает `git pull` и `python3 poster.py run`.
